# Телефонная книга

Веб-приложение на PHP для хранения контактных данных. Приложение позволяет просматривать записи, сортировать и постранично выводить контакты, добавлять новые записи, изменять существующие и удалять их.

## Требования

- PHP 8.1 или новее;
- MySQL 5.7 или новее;
- расширение PHP `pdo_mysql`;
- веб-сервер Apache с поддержкой `.htaccess` либо другой сервер, настроенный на запрет прямого доступа к программным модулям.

## Структура проекта

- `index.php` — единственная точка входа и маршрутизатор приложения;
- `modules/menu.php` — формирование основного меню и меню сортировки;
- `modules/viewer.php` — вывод таблицы контактов и пагинации;
- `modules/add.php` — форма и обработка добавления контакта;
- `modules/edit.php` — список контактов и форма редактирования;
- `modules/delete.php` — список контактов и обработка удаления;
- `config.php` — параметры подключения к базе данных и общие функции;
- `database.sql` — создание базы данных и таблицы `contacts`;
- `assets/style.css` — оформление страниц.

Файлы в каталоге `modules` подключаются только из `index.php`. При прямом обращении к ним выполнение завершается с кодом 404. Все ссылки интерфейса ведут на `index.php` с параметрами маршрутизации.

## Установка

1. Создайте пустую базу данных MySQL средствами локального сервера или панели управления хостингом.
2. Выберите созданную базу данных в phpMyAdmin или другом клиенте MySQL и выполните команды из файла `database.sql`.
3. Откройте `config.php` и укажите параметры подключения: `DB_HOST`, `DB_NAME`, `DB_USER` и `DB_PASSWORD`.
4. Разместите файлы проекта в корневом каталоге сайта на PHP-хостинге.
5. Откройте `index.php` в браузере.

Для локального запуска при установленном PHP и работающем сервере MySQL можно использовать встроенный веб-сервер PHP:

```bash
php -S localhost:8000
```

После запуска откройте `http://localhost:8000/index.php`.

## Возможности

- вывод контактов по 10 записей на странице;
- сортировка по порядку добавления, фамилии и дате рождения;
- добавление, редактирование и удаление контактов;
- проверка обязательных полей и корректности адреса электронной почты;
- подготовленные SQL-запросы и экранирование выводимых пользовательских данных.
